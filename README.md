
Este repositorio contiene dos ejercicios hechos en Java, que tiene como proposito practicar el uso de clases, herencia, validación de datos y organización del código. Cada ejercicio tiene su propio main

Ejercicio 1: Sistema de Juegos

En este ejercicio se crea un sistema para registrar diferentes tipos de juegos. Se trabaja con dos clases principales: MarioBros y CarreraVehiculos, ambas basadas en una clase abstracta llamada Juego.
El programa permite cargar ejemplos, registrar nuevos juegos, buscarlos por nombre, filtrarlos por tipo y mostrar la lista completa. También usa una excepción personalizada para evitar datos incorrectos.

Ejercicio 2: Sistema de Dispositivos

Este ejercicio maneja dispositivos como laptops y teléfonos, todos basados en una clase principal llamada Dispositivo. Cada tipo tiene sus propios datos adicionales.
Se crean varios objetos de prueba y se validan los errores con una excepción personalizada. Al final, se muestra la información usando polimorfismo, lo que permite que cada dispositivo muestre sus datos según su tipo.
